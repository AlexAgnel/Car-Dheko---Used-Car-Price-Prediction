# Car Dheko - Used Car Price Prediction

## Project Overview
This project is an end-to-end Machine Learning application developed to predict used car prices based on various car features such as brand, fuel type, transmission, mileage, engine capacity, ownership, and manufacturing year.

The project covers the complete Machine Learning workflow including:
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Building and Evaluation
- Streamlit Web Application Deployment

The main objective of this project is to build an accurate and interactive used car price prediction system using real-world car data.

# Project Workflow

## 1. Data Collection
Collected used car dataset containing multiple vehicle specifications and pricing details.

## 2. Data Cleaning
Performed preprocessing techniques such as:
- Handling missing values
- Removing duplicates
- Cleaning inconsistent data
- Converting data types
- Formatting numerical columns

## 3. Exploratory Data Analysis (EDA)
Analyzed the dataset using visualizations and statistical methods to understand:
- Price distribution
- Brand-wise car analysis
- Fuel type analysis
- Transmission analysis
- Feature correlations

## 4. Feature Engineering
- Encoded categorical variables
- Scaled numerical features
- Prepared data for machine learning models

## 5. Model Building
Implemented and compared multiple regression models:
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

## 6. Model Evaluation
Evaluated model performance using:
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## 7. Streamlit Web Application
Built an interactive Streamlit application where users can enter car details and predict used car prices instantly.

# Installation

## Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Car-Dheko-Used-Car-Price-Prediction.git
```

## Navigate to Project Folder

```bash
cd Car-Dheko-Used-Car-Price-Prediction
```

## Install Required Libraries

```bash
pip install -r requirements.txt
```

## Run Streamlit Application

```bash
streamlit run app.py
```
